Tehniskā specifikācija

Versija 1.0 · 2026. gada augusts
MAPES — Vadības sistēmas arhitektūra

1. Dokumenta mērķis

Šis dokuments apraksta «Procesu reģistra» informācijas sistēmas tehnisko arhitektūru, datu modeli, integrācijas un izvietošanas prasības izstrādei, uzturēšanai un pārcelšanai uz iestādes darba vidi.

2. Sistēmas kopsavilkums

Procesu reģistrs ir tīmekļa lietotne procesu, galaproduktu (GP), procesu jomu, normatīvo aktu (NA) un izpildītāju uzskaites un pārvaldības atbalstam. Lietotne ir statiska — HTML, CSS un JavaScript — bez build soļa un bez atsevišķa backend servera repozitorijā.

  • Lietotāja saskarne: index.html + modulāri .js faili
  • Datu glabāšana: Supabase (PostgreSQL + Storage)
  • Hostēšana: statisks HTTPS (GitHub Pages, iestādes web serveris)
  • Neatbalstīts: atvēršana ar file://

3. Tehnoloģiju stack un atkarības

Procesu reģistrs neizmanto NPM. Nav package.json, nav node_modules, nav build soļa.
